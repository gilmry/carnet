# Carnet — vitrine publique

Documentation vivante de **Carnet**, plateforme numérique et de conformité des résidences autonomie,
construite d'abord avec la Résidence de la Médaille Militaire (Hyères).

Ce dépôt ne contient **aucun code** : il sert, par GitHub Pages, la vitrine assemblée par le gate
`doc-vivante` du dépôt de développement (privé). À chaque story livrée, le parcours de référence est
rejoué sur un serveur réel et filmé avec Playwright ; le film, la capture et les chapitres sont
poussés ici automatiquement par le workflow « Vitrine » du dépôt source.

- Vitrine : https://gilmry.github.io/carnet
- Contenu : `index.html`, `videos/`, `images/` — **générés, ne pas éditer à la main**.
- Aucune donnée réelle de la résidence : tout ce qui est montré est fictif.

Chaque publication automatique porte le message `vitrine : gilmry/rmm@<sha>`, qui identifie le
commit source.
